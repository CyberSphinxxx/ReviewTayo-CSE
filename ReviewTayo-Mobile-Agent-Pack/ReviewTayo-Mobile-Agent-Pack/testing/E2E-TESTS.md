# E2E Journeys

Use Maestro or another approved mobile E2E tool compatible with the chosen Expo workflow.

Required:
1. Fresh install → onboarding → first practice.
2. Guest Professional → Home → Smart Drill → result.
3. Sub-Professional → Clerical appears.
4. Wrong answer → explanation → Try Another Like This.
5. Review Due → Again → Got It → completion.
6. Settings → Light/Dark/Device.
7. Practice → Mock → result.
8. Offline practice → app restart → state retained.
9. Interrupted quiz → resume.
10. Interrupted mock → resume.
