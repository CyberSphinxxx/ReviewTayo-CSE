# Product Requirements

## Product
**ReviewTayo: CSE**

A mobile-first Civil Service Examination study companion for Filipino learners.

## Primary user promise
Open the app and immediately know what to study next.

## v1 exam scope
- CSE Professional
- CSE Sub-Professional

The UI is CSE-specific for v1, while the domain/data model is exam-generic.

## Core product loops

### Daily loop
Home → recommended action → practice/review → feedback → next action → Done For Today.

### Learning loop
Learn → topic/resource → concept understanding → Practice.

### Practice loop
Practice → choose a purpose → quiz → answer feedback → result → recommended next action.

### Recovery loop
Wrong answer → concise explanation → Try Another Like This / Review Concept → mastery/review queue update.

### Review loop
Review Due → flashcard/question review → Again/Got It → reschedule → caught-up state.

### Mock loop
Mock setup → timed session → interruption-safe persistence → result → subject breakdown → next study plan.

## Non-goals for v1
- public leaderboards
- coins/gems/hearts
- social feed
- chat-first AI tutor
- subscriptions/payments
- multi-exam switcher in main UI
- production store submission itself
