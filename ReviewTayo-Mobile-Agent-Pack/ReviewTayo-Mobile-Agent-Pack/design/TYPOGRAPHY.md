# Typography

Preserve Claude/reference direction:
- editorial serif for major Home/onboarding display moments
- clean cross-platform sans for controls/body
- use bundled/open cross-platform fonts if necessary for consistent rendering

Roles:
- Display
- Page title
- Section title
- Card title
- Body
- Metadata
- Eyebrow
- Button
- Navigation

Support dynamic text sizes and onboarding Standard/Large/Extra Large.
