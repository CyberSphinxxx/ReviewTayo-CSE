# Design System

## Principle
Same component structure in light and dark. Themes change tokens, not IA.

## Light
Warm cream/paper + ReviewTayo maroon.

## Dark
Deep burgundy/near-black surfaces + cream text + rose accents + restrained gold for highest-priority action.

## Components
Build reusable primitives before screens:
- typography
- buttons
- surfaces
- list rows
- badges
- segmented controls
- progress
- bottom nav
- owl mark
- modal/sheet
- empty/error states

No magic colors inside screens.
