# Core Components

Create stable primitives:
- `RTButton`
- `RTIconButton`
- `RTSurface`
- `RTListRow`
- `RTBadge`
- `RTProgress`
- `RTSegmentedControl`
- `RTBottomNav`
- `RTOwlMark`
- `RTEmptyState`
- `RTErrorState`
- `RTSheet`
- `RTStat`
- `RTChoice`
- `RTQuestionChoice`

Use variants rather than copy-pasting style objects per screen.
