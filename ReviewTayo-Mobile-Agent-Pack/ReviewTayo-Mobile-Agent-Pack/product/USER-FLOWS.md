# User Flows

## First launch
Onboarding → generated plan → first practice → Home.

## Daily
Home → recommended action → result → next action → review due → Done For Today.

## Wrong answer
Question → incorrect → explanation → Try Another Like This / Review Concept → continue.

## Review
Review → Review Due → Again/Got It → reschedule → completion.

## Mock
Practice → Mock → setup → exam → result → next 7-day recommendation.

## Offline
Open offline → study normally → persist locally → reconnect → background sync.
